# 모아

TOPIK（韓国語能力試験）向けの、自分用の学習アプリです。単語・文法・書き（51〜54番）の練習と、学習記録をまとめています。

- HTMLとJSだけで動きます（ビルド不要）
- 学習記録はブラウザ（localStorage）に保存され、GitHubには送られません
- スマホのホーム画面に追加すると、アプリのように開けてオフラインでも使えます
- 検索エンジンには載らない設定（noindex）にしています

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリの一番上に置いて push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## 記録のバックアップと引っ越し

記録はその端末のブラウザにだけあり、端末どうしの自動同期はありません。

- **書き出す**：**記録** タブのいちばん下 →「ファイルで書き出す」（できないときは「テキストでコピー」）
- **読み込む**：同じ場所の「読み込む」からファイルを選ぶ（またはテキストを貼りつけ）。今の記録は置きかわります
- 最後の書き出しから7日たつと、ホームにお知らせが出ます（「今日はあとで」でその日は消えます）

アーティファクト版から移すときは、Claudeに「모아のデータを書き出して」と頼んでファイルを作ってもらい、それを読み込みます。

書き出したファイルは個人の学習記録なので、リポジトリには入れないでください（`.gitignore` で除外しています）。

## 書きの添削

51〜54番の問題画面にある「Claudeに添削を頼む（文章をコピー）」を押すと、問題・自分の答え・採点の観点をまとめた依頼文がコピーされます。Claudeアプリに貼って送ると、点数・良い点・直す点・直した答案が返ってきます。

## 単語や問題を足す・直す

データは `data/` に分かれているので、GitHubの画面（スマホのGitHubアプリでも可）から直接編集できます。

| ファイル | 中身 |
| --- | --- |
| `data/words.js` | 単語（`A_RAW` 頻出A / `B_RAW` 頻出B / `C_RAW` 追加 / `M_RAW` 中級 / `L_RAW` 4級）、まぎらわしい単語・副詞・漢字語・多義語 |
| `data/grammar.js` | 文法項目と文法シート |
| `data/writing.js` | 書き 51〜54番の問題と模範解答 |

単語は1行1語で `["韓国語","意味","例文","例文の訳"],` の形です。前の行の最後に `,` があるか確認してください。保存（commit）すると1〜2分で反映されます。

アプリの「単語を追加」から足した単語は、このファイルではなくブラウザ側の記録に入ります。

## アーティファクト版とのちがい

| 機能 | アーティファクト版 | GitHub版 |
| --- | --- | --- |
| 単語・文法・書きの練習 | ○ | ○ |
| 単語の追加・学習記録 | ○ | ○（この端末に保存） |
| 端末間の自動同期 | ○ | ×（書き出し/読み込みで移す） |
| 書きの添削 | アプリ内でAI添削 | 依頼文をコピーしてClaudeアプリで |
| 単語の意味の自動入力 | ○ | × |

## ファイル構成

```
index.html            アプリ本体
data/                 単語・文法・書きのデータ
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン
sw.js                 オフライン用（ファイル構成を変えたら VERSION を上げる）
icons/                アイコン
.nojekyll             GitHub Pages でそのまま配信するための空ファイル
```

## 更新するとき

ファイルを差しかえて push するだけです。ページはネット優先で読み込むので、次に開いたときに反映されます。

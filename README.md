# 모아

TOPIK（韓国語能力試験）向けの、自分用の学習アプリです。単語・文法・書き（51〜54番）の練習と、学習記録をまとめています。

- 1つのHTMLファイルで動きます（ビルド不要）
- 学習記録はブラウザ（localStorage）に保存され、GitHubには送られません
- スマホのホーム画面に追加すると、アプリのように開けてオフラインでも使えます

## GitHub Pages で公開する

1. このフォルダの中身をリポジトリの一番上に置いて push する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

## アーティファクト版からの引っ越し

ブラウザの保存場所はサイトごとに別なので、記録は自動では移りません。

1. アーティファクト版のデータを書き出したファイル（`moa-backup-….json`）を用意する
   - アーティファクト版には書き出しボタンがないので、Claudeに「모아のデータを書き出して」と頼んで作ってもらう
2. GitHub版の모아で **記録** タブ → いちばん下の「読み込む」からファイルを選ぶ（またはテキストを貼りつけ）
3. 自動で再読み込みされ、追加した単語・苦手・覚えた単語・学習記録・書きの答えが移ります

GitHub版どうし（PC⇔スマホなど）で移すときは、**記録** タブの「ファイルで書き出す」→ もう一方で「読み込む」です。端末どうしの自動同期はないので、ときどき書き出しておくと安心です。

書き出したファイルは個人の学習記録なので、リポジトリには入れないでください（`.gitignore` で除外しています）。

## アーティファクト版とのちがい

| 機能 | アーティファクト版 | GitHub版 |
| --- | --- | --- |
| 単語・文法・書きの練習 | ○ | ○ |
| 単語の追加・学習記録 | ○ | ○（このブラウザに保存） |
| 端末間の自動同期 | ○ | ×（書き出し/読み込みで移す） |
| 書きのAI添削・単語の意味の自動入力 | ○ | ×（ボタンが出ないだけで、ほかは普通に動きます） |

## ファイル構成

```
index.html            アプリ本体（単語・文法・問題データもここに入っています）
manifest.webmanifest  ホーム画面に追加したときの名前・アイコン
sw.js                 オフライン用（本体を大きく変えたら VERSION を上げる）
icons/                アイコン
.nojekyll             GitHub Pages でそのまま配信するための空ファイル
```

## 更新するとき

`index.html` を差しかえて push するだけです。ページはネット優先で読み込むので、次に開いたときに反映されます。
